# 无标签观测探索实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已获授权的质量检查与探索范围内，区分时间覆盖与记录缺测，核对QC和数值的对应关系，保留异常上下文，形成可复现报告。

**Architecture:** 新脚本直接只读官方小时CSV，不把上一轮诊断Parquet作为原始数据。按公开元数据声明的起止标签裁剪描述窗；所有分组、掩膜和统计另存，不回写附件。另读既有日温原值Parquet制作完整月份的背景描述。

**Tech Stack:** 项目现有mc-base、Python/pandas/numpy/matplotlib、标准库unittest。

**Spec:** 用户2026-10-27要求及`docs/pending-questions.md`、`config/analysis-constraints.yml`。本次是前述已授权探索工作的继续，不新增建模决策或对外操作。

## Global Constraints

- 原始数据只读，无新增插补，无自动删除QC记录。
- 观测为UTC+8；小时统计区间未知，图表称“标签”，不定义最终预警边界。
- 不将案例10:30视作任何已确认灾害阶段，不生成最终标签。
- 不累计、滚动求和或求强度化降水；降水仅检查原记录缺测和QC列是否存在。
- 覆盖窗采用官网起止记录标签，不能称仪器真实运行时段；分组统计不构成最终QC准入政策。
- 无随机算法，无模型训练、显著性筛选或因果/预报准确率声明。

## Review Focus

- 首尾空段与内部缺段混淆：分别统计全年标签、官网声明窗和字段首末数值之间的缺段。
- QC=0但数值缺失、QC=8但有数值：交叉表保留，不以QC替换数值或反向赋码。
- Precip及FLUX无QC字段：明确“未提供”，不能给默认0。
- 连续缺段遇年界：合并后计算，保留两端闭区间标签和标签数，不截断到年内。
- 不完整2025日温月份：不与完整月份均值直接叠画；2025全年不参与年均比较。
