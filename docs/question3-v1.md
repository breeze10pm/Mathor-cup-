# 第三问技术交付 v1：可预报性、触发时间约束与条件到达情景

更新：2026-10-28（北京时间）。本文是可运行技术版本，不是论文。第二问和第四问冻结结果未修改。

## 当前结论

现有资料不能支持**灾前泥石流物理触发时刻预测、名义95%触发时间预测区间、区间经验覆盖率或真实业务预警提前量**。本版已完成事件证据整理、模式数据可得性审查、条件到达情景、空间轨迹导出和时间/速度敏感性。所有不确定性和信息泄漏均显式保留。

用户时间线为北京时间UTC+8：10:52冰岩崩起始、10:54:19–10:55:10碎屑流向泥石流转化关键阶段、10:59到达口岸；实际物理触发秒数未知。赛题文本10:30单独保留，其目标阶段和时区均未确认。转化阶段不能自动等同物理触发时刻。

## A. 灾前时间预报可行性

第二问提供的动态信息中，GFS是0.25°/6小时预报样本；WRF d01是约9.014 km、逐小时模式场。GFS NetCDF全局属性`initialization_time`、WRF NetCDF属性`START_DATE`和`SIMULATION_START_DATE`均记录2026-08-25 00:00 UTC，对应用户事件线起始前26小时52分。核对两文件全局元数据后，没有发现可识别的产品生成时间或历史公开时间；本地文件系统下载/修改时间不作为生成或公开时间。相邻有效样本为GFS北京时间08:00/14:00、WRF北京时间10:00/11:00。事件的51秒转化阶段相对6小时和1小时步长分别短约423.5倍和70.6倍；模式格点距A/B约4.5–5.1 km（WRF）或4.6–5.1 km（GFS），距口岸核心约6.0 km（WRF）、12.5 km（GFS）。这些距离和网格尺度不足以解析坡面级转化过程。

本地文件只可核实模式初始化和有效时刻；模式生成时刻、产品公开可得时刻、历史告警签发时刻均没有记录。因而：

- GFS可视为一个具有事前初始化时间的数值预报产品，但无法证明对应循环当时何时公开可得，也无法计算可复现的业务提前量。
- WRF d01的资料没有运行生成/发布时间或业务预报状态证明，不能写成“事前业务预报”。
- 不将GFS六小时累计或WRF逐小时累计插值成秒级观测。GFS降水累计窗口端点语义也尚未核实。
- 第二问静态地形、冰川格网、岩屑坡和河网指标不含逐时变化或经过校准的时间临界判据，不能直接产生触发时刻。未知水分、流量、冰岩力学参数不填零、不填一。

时间天气上下文保存在`forecast_assumptions.csv`，其中分别列模式初始化、有效时间、模式生成时间、公开可得时间，并对缺失时间留空。时间分辨率与格点代表性沿用第二问计算表，未重新插值或重新估计。

## B. 事件检测后的条件预报

沿用冻结的第四问中心线与情景速度配置。A源点至口岸核心点的投影中心线距离为22.156 km，B为21.993 km；源点分别偏离中心线约1.00 km和1.38 km。假设**上游冰岩崩在报告的10:52被即时检测、无处理延迟**，沿线平均速度以用户报告的10:52至10:59反算，再对该速度乘现有配置的0.85/1.00/1.15敏感系数，则口岸条件到达范围为10:58:05–11:00:14，对应检测后约6分05秒–8分14秒；1.00基准恰为10:59。

这不是独立预测：基准速度直接使用了10:59到达时间，命中10:59是按该时间反算速度导致。0.85/1.15不是现场速度概率分布，也不是置信限。条件提前量假设检测发生在10:52且告警零延迟；真实预警签发时间、延迟和业务提前量仍为null。它描述的是源区事件检测后的路径传播情景，不表示第三问已经得到可靠的灾前触发预测。

五秒时间步坐标是第四问运动学脚本采样得到的模拟前锋位置，秒数是数值输出步长，不是观测时间精度。10:54:19和10:55:10所对应的模拟位置只沿用第四问恒速场景；转化阶段的地理位置没有观测，不把它当作真实前锋位置。未改变第四问的速度、传播位置或物理结论。

## 95%区间、精度敏感性和验证

`trigger_time_intervals.csv`分别列：

1. 条件事件链界限[10:52,10:59]：只在“同一灾害链、触发不早于冰崩起始且不晚于口岸到达”的假设下成立，不是置信区间；
2. 用户报告的转化阶段[10:54:19,10:55:10]：是过程阶段窗口，不等于物理触发时间；
3. 名义95%触发预测区间：下/上界留空，状态为不可估计。

缺乏可信的触发时间误差分布，不能设均匀/正态分布。现有只有单次用户报告事件，没有多起独立、精准的触发标签，因此名义95%区间及经验覆盖率不可估计；“转化阶段落在事件链约束内”只是一致性检查，不是95%覆盖验证。

`question3_sensitivity.csv`对速度系数0.85/1.00/1.15分别计算确定性到达情景；也列分钟级起始/到达时间戳和秒级转化时间戳的容差敏感性。±30秒、±60秒、±0.5秒、±1秒均是明确标注的端点容差假设，只给时间长度上下界，不分配概率质量，不叫95%区间。

信息泄漏检查发现：事件锚定速度用报告的起始与到达时间反算，因此不能用该事件验证模型准确性；UNESCO/UNOSAT范围与本次事件为同一事件，只用于独立图层的空间对照，不参与速度/参数拟合，也不是独立验证数据。当前没有训练集/验证集事件划分。

## C. 空间距离与QGIS图层

`q3_front_trajectories.csv`包含A/B、慢/基准/快三种场景在每个模型采样时刻的链程、高程、剩余距离、北京时间和UTM坐标；`q3_arrival_scenarios.csv`为六种A/B×速度情景摘要。`question3_spatial_scenarios.gpkg`的图层包括：

- `candidate_routes_A_B`：两个候选中心线路径；
- `scenario_front_trajectories`：五秒步长情景路线前锋轨迹；
- `conditional_port_arrival_points`：情景到达点及到达时刻；
- `unesco_extent_comparison`、`unosat_extent_comparison`、`unosat_detachment_comparison`：分别保留的卫星判读范围；
- `reference_points`：A/B源区和口岸核心位置。

卫星范围只反映同事件解译边界，不是模型外推的预测范围。`spatial_distance_range.csv`分别记录22.156/21.993 km路线距离，以及UNESCO约37.35 km²、UNOSAT约64.91 km²几何范围和参考点包含情况；不同产品不合并为一个“真实边界”。
