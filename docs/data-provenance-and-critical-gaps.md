# 数据来源、模拟数据与关键缺口

更新：2026-10-28。区分观测/遥感产品、数值模式、空间解释结果和本项目情景计算，防止把模拟当实测。

## 已用数据中哪些是模拟或参考值

| 数据/结果 | 属性 | 本项目中的用途 | 不能据此声称 |
|---|---|---|---|
| GFS 0.25°降水、云与水成物预报场 | 全球数值天气预报模式输出；非雨量计观测 | 事件时段粗尺度天气背景，网格约25–28 km | 源区局地实测降水、业务发布时刻、独立观测验证 |
| WRF d01 `wrfout` | GFS驱动/相关配置待核实的区域数值模式输出；约9 km网格 | 核心区附近气象背景及降水过程回溯 | 站点实测、源区精细降水，或事件发生时已公开可用的预报 |
| WRF d02 | 目前未取得 | 未用于现有结果 | 不存在可引用的d02计算结论 |
| TPCSM 5 km产品 | 官方说明为WRF V4.0逐小时10天数值模拟；目录中可下载但当前四问首版未使用 | 备选长时段模拟数据 | 现场观测或独立模式验证；与WRF共源时不能当独立证据 |
| 84处历史灾点 | 官方空间灾点/解译资料，缺逐事件发生时间 | 第二问空间对照和成因分层背景 | 小时级正样本、训练用可靠标签或无灾害负样本 |
| 站点逐小时综合观测 | 实测观测产品，但含提供方QC/插补口径；缺测定义须按元数据处理 | 第一问区域气象背景；事件临近窗口辅助核对 | 源区现场气象；单站无雨不能证明全流域无雨 |
| 2019 DEM、灾后DEM/影像、GF7/正射产品 | 遥感/摄影测量派生产品，不是地面连续测量；日期、垂直基准、云洞和定位误差各异 | 地形、变化和影响区判读 | 同日全程灾前后差分、未验证的堆积厚度 |
| geo-pera v1.1 dh、1σ和分段冲淤预算 | 基于立体影像测量、配准、掩膜和校正的高程变化产品；不是物理模型模拟，也非现场钻测 | 口岸邻近河段冲淤和测量不确定性参考 | 将负dh写成堆积，或用其沉积量代表整条沟道 |
| 公开中心线 | 地理空间数据产品；含沿程坐标/高程，非本项目观测流迹 | 候选路线距离、剖面和一维情景路线 | 精确泥石流轨迹或实测流速 |
| 第四问前锋轨迹、到达敏感性和转化时段位置 | 本项目建立的一维恒速/速度倍率情景模拟 | 展示路线、时间和参数敏感性 | 二维水动力或流变模型、真实流深/流量/堆积厚度、独立验证预测 |
| `±15%`速度倍率、10:54:19代表点、5200/4000/1800 m及约22 km | 参考值/用户报告输入；精度依来源而异 | 可复现的情景参数与过程描述 | 实测参数精度或统计置信范围 |

关键原则：GFS、WRF、TPCSM均属于数值模式信息；站点观测和遥感派生产品应分开标记。本项目目前的第四问“模拟”是透明的一维运动学情景，并未运行成熟的二维泥石流动力学求解器。

## 推动四问完成的关键数据

| 题目 | 最关键的已有数据 | 仍最关键的缺口 |
|---|---|---|
| 第一问：关联因素 | 吉隆高寒山区逐小时观测及其字段/QC说明；GFS/WRF作为补充背景；赛题案例时间线 | 源区同位置同时间气象/雪冰/土壤水观测；多个独立灾害与无灾事件的日期标签。否则仅能做单例背景对照，不能验证普适关联 |
| 第二问：触发/危险性条件 | 84处历史灾点及机制类别、DEM、河网/岩屑坡、冰川/冰湖、候选源区A/B、灾后影响范围、近场GFS/WRF背景 | 可靠事件时间和成因标签、源区降水/融水/冰湖水文、物源范围与体积、现场流深/水痕。缺少这些就不能训练可信概率分类器或阈值 |
| 第三问：时间预报 | 用户报告的10:52冰崩、10:54:19–10:55:10转化关键时段、10:59到达；GFS/WRF起报时刻 | 转化时刻的原始记录/时间同步误差，实际泥石流触发时刻，天气预报公开时间和预警签发记录，以及多个事件验证集。现有时刻只能约束单例过程，不能校准95%预报区间 |
| 第四问：传播/范围 | 公开沟道中心线、源区A/B和口岸核心点、卫星解译影响范围、灾后高程变化dh/1σ及沉积预算 | 全程同基准灾前地形、现场断面/流深/流量/流速、冰崩物质量/含水率和材料流变参数、独立到达/边界记录。缺失时保留一维情景，不输出堆积厚度真值 |
